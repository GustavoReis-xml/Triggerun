# Trabalho das IAs neste projeto

Antes de alterar código, leia `ai/README.md` e `ai/STATE.md`; depois leia somente a tarefa e as referências necessárias. Este fluxo vale para Codex, Antigravity e outros assistentes que acessem esta cópia do projeto.

Registre a responsabilidade pela tarefa em `ai/TASKS.md` antes de editar. Não sobrescreva trabalho de outra IA ou do usuário. Instruções diretas do usuário prevalecem. Use `ai/templates/HANDOFF.md` ao passar trabalho; mantenha o estado resumido e diferencie implementação, teste automatizado, teste com cliente e instalação na Oracle.

Priorize precisão e eficiência sobre velocidade. Leia métodos, arquivos completos e logs integrais quando forem úteis para entender o comportamento; isso vale para todas as IAs. Use buscas para orientar a investigação, sem limitar artificialmente o contexto necessário. Antes de modificar arquivos de execução existentes, preserve uma cópia dos arquivos afetados em `backups/`; antes de instalar na Oracle, preserve também a versão remota. Confira sintaxe e testes pertinentes antes de reiniciar. Documentação nova não exige backup remoto nem reinício.
